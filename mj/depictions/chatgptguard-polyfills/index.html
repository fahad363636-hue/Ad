ChatGPT WebKit Guard (Polyfills)

Version 0.1.0 · Free / مجاني · Experimental / تجريبي

Experimental ChatGPT-only CSS gradient crash workaround for iOS 16 WebKit using PoomSmart Polyfills. For Safari and other compatible browsers. Requires Polyfills (>= 2.29.0); not a guaranteed fix on every iPhone. No license required.

العربية

حل تجريبي لتعطّل ChatGPT بسبب تدرجات CSS في WebKit على iOS 16. يستخدم أداة Polyfills من PoomSmart، ويعمل في Safari والمتصفحات المتوافقة بحسب الجهاز. يتطلب Polyfills (2.29.0 أو أحدث). ليس مضمونًا على كل آيفون، وهو مجاني دون ترخيص.
